# libxposed dependencies

Modern API is compile-only and supplied by the installed framework. Service and interface libraries are packaged in the companion app.

- io.github.libxposed:api:101.0.0
- io.github.libxposed:service:101.0.0
- io.github.libxposed:interface:101.0.0

Publisher: libxposed. License: Apache License 2.0; full text in `LICENSE-libxposed.txt`. Unmodified binary libraries retrieved from Maven Central; source archives and artifact metadata retained in the development workspace.

Project links: https://github.com/libxposed/api and https://github.com/libxposed/service

Artifact repository: https://repo.maven.apache.org/maven2/io/github/libxposed/

Native integration follows the documented LSPosed Native Hook API. The module does not bundle a separate Dobby engine or modify framework configuration.
