# 2.1.0 固定 ELF 跳板

发行状态更新（2026-11-03）：按用户要求改为正式发行，原始安装包、标签和下载链接保持不变，文件名中的 candidate 为原始构建标识。下文保留初始验证范围；本次没有新增设备验收。用户反馈兼容方案使用期间出现 12 小时封禁，具体模块版本和原因未确认，不保证账号安全。保留 0.4.1、0.4.2、2.0.1。

2026-11-03。此实现尝试减少实际驻留内容，不用改名、maps 过滤、假 JIT 标识或检测函数 Hook 来隐藏。成功的 2.0.1 ZIP 与原 LSP 模块不改，2.1.0 在没有手机验收前不替代成功版本。

## 这次实际改变

1. **不再链接 Dobby。** 保留相同的一个游戏私有 protobuf 编码入口，签名、加密、发送和原登录过滤器不变。原代码的全部系统网络、证书、GOT 和公共库 Hook 数量仍为零。
2. **原函数跳板位于模块已有的 ELF RX 段。** 编译时固化经过核对的原编码函数前 16 字节，执行后通过普通数据指针跳回原函数 +16。没有通用重定位器、动态可执行 arena、mmap/memfd_create 导入或跳板代码写入步骤。该跳板与模块其他代码共用已有可执行映射；具体 backing 路径仍由 Zygisk Next 决定，不保证它显示为普通磁盘路径。
3. **缩小权限写入面并检查错误。** 只对目标函数所在的一页短暂设置 RWX，写入后检查恢复 RX 的结果；恢复失败就恢复原入口并重试 RX，不报告安装成功。不需要为原函数跳板另开 RWX 写入窗口。安装前要求目标与静态跳板均可确认为 RX，无法确认则不安装。
4. **保持日志和控制方式。** 一个开关、选包、开机自动加载、Root 持久日志、复制与 Download 导出均保留。诊断新增 `backend=fixed_elf_trampoline` 和 `file_backed_trampoline_selected`。关闭/开启或换目标仍需完全重开游戏。

这不是通用 Hook 引擎，只支持固定的官方 ARM64 Lua 库：SHA256 `7f61316eb49e95e416b2a96b744b3eb0cc94d9347bf3c3f5c5cf983bb18a05a6`。仍验证 GNU Build ID、API 可执行范围和原入口 32 字节。库或入口不符就拒绝，不能拿本汇编复制到其他函数或版本。

## 收益和明确保留的风险

可以从实现和 ELF 确认：本模块不再分配独立匿名可执行跳板页；不包含 Dobby 引擎和对应字符串；跳板本身不需要运行时修改；基础系统库依赖没有增加，仍为 libc/libdl/liblog/libm。

这不等于整个进程没有匿名 RX。Zygisk、ART/JIT、Unity 或其他模块仍可能创建它们。目标代码页写入后也可能有 COW/Private_Dirty 痕迹。模块 SO、16 字节入口修改、分支指令、Root companion 与日志进程仍可见。短暂 RWX 窗口仍存在，不能为了消除它在并发运行的代码页上直接去掉 X。

入口写入不是 stop-the-world，也不提供原子 16 字节指令替换。这一点不能用离线测试消除；目前沿用启动期安装的约束，实际并发与第一条编码调用时机须手机验证。没有声称更低封号概率、绕过某款风控或完全无痕。

## 验证

- 使用实际链接产物进行 ARM64 模拟：32 组随机寄存器/向量寄存器与栈内容，比较原前 16 字节和静态跳板执行后的状态、返回地址。除 ABI 允许的 IP1（x17）临时寄存器，所比较状态一致。另验证入口分支不改变参数、SP 或 LR。
- 主机错误注入覆盖成功、原指令不符、RWX 设置失败、RX 恢复失败后回滚成功、回滚后仍无法恢复 RX、地址和长度无效等情况。不能把这些模拟写成 Android mprotect 已成功。
- 原过滤器通过真实 Lua/protobuf 回归；ELF 打包门禁增加无通用引擎、无可执行分配器导入及静态 RX 跳板存在性检查。
- 2.1.0 的手机启动、跨区登录、缓存重登、对局、重启、SELinux 和实时权限尚未验收。原 2.0.1 的成功反馈不代替本版验收。

## 指令与构建依据

静态跳板复制的是 `sub sp` 和三个保存寄存器的 `stp`，不含 PC 相对取址或跳转；resume 地址在修改入口之前设置。x17 是 AAPCS64 的 IP1 临时寄存器，不能把这里的保存规则推广为任意函数重定位器。[Arm AAPCS64](https://github.com/ARM-software/abi-aa/blob/main/aapcs64/aapcs64.rst)、[Linux mprotect](https://man7.org/linux/man-pages/man2/mprotect.2.html)。

构建：`powershell -File minimal-root/build.ps1`。使用 NDK 26.3.11579264、ARM64/API26，保留 16 KiB LOAD 对齐、非执行栈、完整 RELRO 和两个必要导出。成功 2.0.1 原包哈希仍为 `51382311c68c344f8f0dba0689948e9b26a2c1ff2af7a38a8575eea666a6ad2e`。
