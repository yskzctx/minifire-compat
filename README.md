# 迷枪苹果区兼容 0.4.1

[下载已签名安装包](https://github.com/yskzctx/minifire-compat/releases/tag/v0.4.1) · [构建说明](docs/BUILD.md) · [验证记录](docs/VERIFICATION.md)

主界面只有账号兼容开关和日志入口。开关立即保存，关闭再开启会恢复此前成功的登录配置。覆盖安装保留原设置，无需重新选择实验模式。

0.4.1 增加蓝白卡片界面、开启状态标签、统一日志页样式及自适应桌面图标，仅美化显示，登录与自动生效逻辑不变。

启用后，LSPosed 会在每次启动游戏时自动加载模块，包括手机重启之后；兼容应用无需常驻后台，也无需每次开机打开。更改开关后须彻底退出游戏再进入，因为已经运行的游戏进程仍使用启动时的设置。首次安装默认关闭。

本版使用现代 libxposed API 101 与 Remote Preferences，配置保存在 LSPosed 数据库中，不再使用旧版共享配置功能。实际手机框架 API 为 102，已验证现代模块正常加载，废弃功能提示消失。

修复了缓存重登问题：游戏缓存中的兼容版本号与实际客户端版本号可能分别是 1.0.78／1.0.77；现在会同时规范化这两个已核对的版本字段，不再跳过平台转换导致凭据异常。账号与令牌仍由游戏自己管理。其余游戏版本与库校验保留；适配范围为已核对的官方安卓 1.0.76／1.0.77，成功使用的版本声明配置仅支持完整安装的 1.0.77。

## 使用

1. 覆盖安装 `Minifire-Compat-0.4.1.apk`，保留 LSPosed 启用状态与仅游戏的作用域。需要现代 API 101 或以上的框架。
2. 打开应用，确认“苹果区账号兼容”开关已开启。
3. 以后直接启动游戏即可。无需开机脚本、后台保活服务或额外开机授权。

## 日志

日志页面支持刷新、复制、清空。仅记录固定模块事件、平台、渠道和结果码，不记录手机号、UID、密码、验证码、令牌、原始响应或异常堆栈。

游戏隐藏了本应用时，框架日志读取需要给本应用 Root 权限，仅执行固定的 LSPosed 日志读取命令；读取在后台进行，8 秒超时，最多缓存最近 160 条记录。拒绝日志读取授权不会影响账号兼容。清空只清除此应用的日志显示，不删除其他应用或 LSPosed 的日志。

`native_state stage=4 decode_ready=1` 表示登录编码器初始化完成。`terminal_response code=200` 表示终端登录成功；SDK 的 `auth_result code=0` 是另一套结果码。原角色和对局效果仍以游戏实际显示为准。

## 构建与验证

JDK 17、Gradle 8.14.3、Android SDK 34、NDK 26.3.11579264、CMake 3.22.1。构建命令 `gradle --offline :app:assembleRelease :app:lintRelease`。

纯 Java 测试包括登录策略 20 项、设置恢复 8 项、固定诊断隐私 8 项、开关配置保留 9 项、日志导入隐私 10 项。真实 Lua／Protobuf 桌面测试 21 项，库校验测试 5 项，另有现代 APK 入口、作用域、服务与依赖打包检查。APK 保持相同包名与签名，只有 ARM64 原生库，无联网权限、开机权限或后台服务。

这是用于本人或明确获授权账号的非官方兼容模块，与游戏运营方无关联。仅适用于已核对版本，不承诺未来版本兼容或账号数据跨区迁移，不能用于获取未授权账号或伪造支付。

用户已确认开关、日志正常，缓存认证后再次打开游戏无需重复验证码，完整重启后无需打开兼容应用即可进入原苹果角色，LSPosed 的废弃功能提示消失。电脑另验证了兼容应用被强制停止时，游戏仍自行加载现代模块并返回登录成功。发布附件中的 `0.4.1-验证记录.json` 区分电脑检查与用户反馈。完整重启测试针对登录逻辑相同的 0.4.0；此前成功对局由用户确认，本次界面版本没有额外重复进行完整对局测试。
